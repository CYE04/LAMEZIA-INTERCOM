装到手机主屏幕，像 app 一样使用

① 用手机扫这个码

② 加到主屏幕（iPhone / iPad）

  1. 确认现在用的是 Safari（其它浏览器加不了）
  2. 点屏幕底部中间的 分享 按钮（方框里一个向上箭头）
  3. 在弹出的列表里往下滑，点 添加到主屏幕
  4. 右上角点 添加

装好后桌面会出现一个话筒图标，以后从那里进就行。

② 加到主屏幕（安卓）

  1. 如果上面出现了 「安装到主屏幕」 蓝色按钮，直接点它即可
  2. 没有的话，点浏览器右上角的 ⋮
  3. 选 添加到主屏幕 或 安装应用
  4. 确认 添加

建议用 Chrome。装好后桌面会出现一个话筒图标。

② 装到电脑（音控台建议这样做）

  1. 用 Chrome 或 Edge 打开上面的链接
  2. 点地址栏右侧的 安装 图标（显示器带下箭头）
  3. 确认安装，之后可以像普通软件一样打开

音控台电脑可以把 ?mode=operator 这个地址存成书签，打开就直接进音控台，不用每次选身份。

③ 进去之后

  • 🎤
    敬拜团选你今天用的话筒或乐器，填名字，直接就能用。
  • 🎚️
    音控组需要密码，向负责同工索取。密码只输一次，之后这台设备会记住。

选错了也没关系，界面右上角有「切换身份」可以随时改。
