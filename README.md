# LAMEZIA 敬拜内通

敬拜团和音控组之间的实时内部通讯。手机加到主屏幕当 app 用，不用装任何东西。

- **敬拜团**：点几下就能告诉音控「耳返多点」「话筒没声」，不用在台上打手势。
- **音控组**：一块看板收全部请求，可以标记处理状态、单独回复、发全体通知。

技术上：一个纯静态网页（GitHub Pages）+ 一个 Cloudflare Worker 后端。
没有构建步骤、没有 npm 依赖、没有服务器要维护。日常开销基本为零。

## 部署清单

第一次部署大约 15 分钟。**照着顺序做，不要跳步。**

### 第 1 步：装工具（只需一次）

需要 [Node.js](https://nodejs.org/)（选 LTS 版本，一路下一步即可）。
装完打开「终端」（Mac）或「命令提示符」（Windows），输入：

```bash
node -v
```

能显示版本号（比如 `v22.14.0`）就说明装好了。

### 第 2 步：注册 Cloudflare 并登录

1. 去 [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) 注册，免费套餐足够用。
2. 在终端里进入本项目的 `worker` 文件夹，然后登录：

```bash
cd worker
npx wrangler login
```

浏览器会弹出授权页面，点同意即可。

> ⚠️ 如果这台电脑登录过别的 Cloudflare 账号，先用 `npx wrangler whoami` 确认
> 当前是哪个账号，避免把后端部署到错误的账号下。

### 第 3 步：部署后端

```bash
npx wrangler deploy
```

成功后命令行会打印一个网址，形如：

```
https://ws-lamezia.你的账号名.workers.dev
```

**把这个网址记下来**，第 5 步要用。

### 第 4 步：设置音控密码（很重要，不做没人能进音控台）

```bash
npx wrangler secret put OPERATOR_KEY
```

回车后会让你输入密码，输入后再回车。屏幕上不会显示输入的内容，正常现象。

密码只存在 Cloudflare 服务器上，**不会出现在这个仓库里的任何文件中**，
翻网页源码也找不到。想换密码就重新执行一次这条命令。

> 这一步是唯一挡住「陌生人冒充音控组发全体通知、踢掉所有人」的防线。
> 没设置密码的话，音控台是进不去的（服务器会拒绝所有音控登录），
> 敬拜团那边仍可正常使用。

### 第 5 步：把后端地址填进网页

用文本编辑器打开根目录的 **`config.js`**，找到第一项，把网址填进去
（注意：开头是 `wss://` 不是 `https://`，末尾不要带斜杠）：

```js
WS_URL: 'wss://ws-lamezia.你的账号名.workers.dev',
```

**整个项目只有这一个地方需要填地址。**

### 第 6 步：限制哪些网站可以连后端

打开 `worker/wrangler.toml`，把 `ALLOWED_ORIGINS` 改成你的 GitHub Pages 域名
（只要域名部分，不含仓库名）：

```toml
ALLOWED_ORIGINS = "https://你的GitHub用户名.github.io"
```

改完重新部署一次：

```bash
cd worker && npx wrangler deploy
```

### 第 7 步：开启 GitHub Pages

1. 把代码推到 GitHub 仓库。
2. 仓库页面 → **Settings** → 左侧 **Pages**。
3. **Source** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，Save。
4. 等 1–2 分钟，页面上会出现网址：

```
https://你的用户名.github.io/仓库名/
```

### 第 8 步：分发给同工

把 **安装引导页** 的网址发到群里：

```
https://你的用户名.github.io/仓库名/install.html
```

这一页会自动识别手机型号，只显示对应的图文步骤，并带一个二维码和「复制链接」按钮。

**音控密码请私下单独告知**，不要发在群里，也不要写进这个页面。

## 日常使用

打开链接 → 选身份：

| 身份 | 说明 |
|---|---|
| 🎤 **敬拜团** | 选今天用的话筒或乐器，填名字，直接用。不需要密码。 |
| 🎚️ **音控组** | 需要密码。**每台设备只需输一次**，之后自动登录。 |

选过一次之后，下次打开会直接进入上次的身份。
想换身份点界面右上角的 **「切换身份」**。

音控台的电脑建议把这个地址存成书签，打开就直接进音控台：

```
https://你的用户名.github.io/仓库名/index.html?mode=operator
```

## 改了东西之后

**改动任何前端文件（`index.html` / `cecp.js` / `config.js` / `install.html` / 图标）后，
必须手动把 `sw.js` 里的 `CACHE_VERSION` 加 1**：

```js
const CACHE_VERSION = 'v2';   // 原来是 'v1'
```

不改的话，已经装到主屏幕的手机会一直用旧版本，改动不生效。
这是整个项目唯一需要手动维护的版本号。

改完推到 GitHub 即可，Pages 会自动更新。

## 目录结构

```
index.html          单一入口：进去先选身份（敬拜团 / 音控组）
install.html        发给同工的安装引导页：二维码 + 分平台图文步骤
config.js           ★ 唯一需要填写的配置：后端地址、房间名、显示名称
cecp.js             整个界面（单文件 Web Component，零依赖）
manifest.json       PWA 清单，决定加到主屏幕后的图标和名称
sw.js               离线缓存；改前端后要手动 bump CACHE_VERSION
icons/              各尺寸图标（由 tools/make-icons.py 生成）
vendor/qrcode.js    二维码生成器，本地生成不联网
tools/              构建期工具，不参与运行时
worker/             Cloudflare 后端（Worker + Durable Object）
```

## 常见问题

**打开页面显示「还没填服务器地址」**
`config.js` 里的 `WS_URL` 还是占位符，回到第 5 步。

**一直显示「未连接」**
后端没部署成功，或 `config.js` 里地址填错。
浏览器打开 `https://ws-lamezia.你的账号名.workers.dev/health`，
能看到一段 `"ok": true` 的文字就说明后端是好的，那问题就在地址填写上。

**音控密码输了没反应 / 提示「服务器还没设置音控密码」**
第 4 步没做，或者做完之后没重新部署。执行 `npx wrangler secret put OPERATOR_KEY`。

**微信里打开没有「添加到主屏幕」**
微信内置浏览器不支持。点右上角 `···` → 「在浏览器中打开」，
再按引导页的步骤操作。`install.html` 检测到微信时会自动提示这一点。

**页面能打开但图标 / 样式丢失**
GitHub Pages 把站点挂在 `/仓库名/` 子路径下。本项目全部用相对路径，
正常不会有这个问题；如果你改过代码，检查有没有写成 `/xxx` 这种以斜杠开头的路径。

**换了音控密码，旧设备还能进吗？**
不能。旧设备下次连接会被拒绝并弹出密码框，重新输入新密码即可。

## 安全说明

- **音控权限在服务端校验。** 密码通过 `wrangler secret` 存在 Cloudflare，
  不在仓库里。前端改代码、伪造消息都拿不到音控权限。
- **密码未配置时一律拒绝**，不存在「没配就放行」的情况。
- 连续输错密码会被逐次延迟并断开连接，暴力破解成本很高。
- **敬拜团一侧没有密码。** 任何拿到链接的人都能以敬拜团身份进来发请求、
  看到广播。这是为了让同工零门槛使用而做的取舍——链接按内部群发放即可。
  如果需要给敬拜团也加密码，可以再提。
